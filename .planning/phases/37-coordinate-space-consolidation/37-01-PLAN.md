<objective>
Centralize the G-code-to-renderer coordinate space conversion behind a single inline helper function and replace all five scattered manual Y<->Z swap sites with calls to that helper.

Purpose: The Y<->Z swap (G-code is Z-up, renderer is Y-up) is duplicated across five locations in viewport_panel.cpp. A future change to the coordinate mapping would require updating five sites instead of one. Centralizing this behind gcodeToRenderer() makes the intent explicit and the mapping single-source.

Output: New header src/core/coordinate_utils.h with the helper; viewport_panel.cpp with all five swap sites replaced.
</objective>

1. Use `#pragma once`
2. Include "types.h" (relative, same directory)
3. Define one function inside `namespace dw`:

```cpp
/// Convert a G-code space coordinate (Z-up) to renderer space (Y-up).
/// Swaps the Y and Z components: renderer.x = gcode.x,
///                                renderer.y = gcode.z,
///                                renderer.z = gcode.y
inline Vec3 gcodeToRenderer(Vec3 v) {
    return Vec3{v.x, v.z, v.y};
}
```
